# 📊 Power BI Stock Inventory Dashboard

An interactive Power BI dashboard developed to analyze stock and inventory data, supplier information, order details, item specifications, and stock movement.

## 🚀 Project Overview

This project demonstrates an end-to-end Power BI data analytics workflow:

- Data extraction from source files
- Data cleaning using Power Query
- Handling null and error records
- Data transformation
- Column type standardization
- Stock and inventory analysis
- Interactive dashboard development
- Business-focused reporting

## 🛠️ Technologies Used

- Power BI
- Power Query
- Excel
- DAX
- Data Transformation
- Data Visualization

## 🔄 Data Preparation

Power Query was used for:

- Removing unnecessary rows
- Handling null values
- Filtering invalid records
- Transforming columns
- Correcting data types
- Combining multiple source files
- Error handling
- Standardizing buyer and item information

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Total Stock
- Buyer-wise Stock
- Order-wise Stock
- Item-wise Analysis
- Supplier/Buyer Distribution
- Stock Trends
- Inventory Information
